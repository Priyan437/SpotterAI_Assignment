# SpotterAI_Assignment

## Required Dependencies

This project uses the following Python libraries:

```txt
pandas
numpy
matplotlib
seaborn
scikit-learn
```

## Setup Instructions

1. Clone the repository:

```bash
git clone  https://github.com/Priyan437/SpotterAI_Assignment.git
cd SpotterAI_Assesment
```

2. Create and activate a virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
```

For Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

3. Install the dependencies:

```bash
pip install -r requirements.txt
```

4. Start Jupyter Notebook:

```bash
jupyter notebook
```

5. Open the notebook file:

```bash
SpotterAI_Assessment_.ipynb
```

6. Run all cells in order from top to bottom.

## Optional: Run Notebook Non-Interactively

If you want to execute the notebook from the command line:

```bash
jupyter nbconvert --to notebook --execute SpotterAI_Assessment_.ipynb
```

## Important Note

- Make sure the CSV files are present in the project directory before running the notebook.
